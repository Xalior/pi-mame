# Timex Sinclair 1500

![Timex Sinclair 1500 at power-on](images/ts1500.jpg)

- **`make kernel MACHINE=ts1500`** — Sinclair
- **Year**: 1983
- **Manufacturer**: Timex Sinclair
- **Television**: PAL

## At power-on

The ZX-81 with 16K on board in a TS-1000 case, the inverse-video K cursor on the NTSC canvas.

## Required assets

- `roms/ts1500.zip`

  | ROM | CRC32 |
  |---|---|
  | `d2364c_649.u2` | `7dd19c48` |

## Notes

- MAME driver: `zx.cpp`.
- MAME clone of `zx81` (ZX-81) — the system macro's parent field in the driver source. The ROM table above lists every member this machine's own zip needs.
