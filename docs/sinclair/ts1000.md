# Timex Sinclair 1000

![Timex Sinclair 1000 at power-on](images/ts1000.jpg)

- **`make kernel MACHINE=ts1000`** — Sinclair
- **Year**: 1982
- **Manufacturer**: Timex Sinclair
- **Television**: PAL

## At power-on

The American ZX-81, the inverse-video K cursor on the NTSC canvas.

## Required assets

- `roms/ts1000.zip`

  | ROM | CRC32 |
  |---|---|
  | `zx81a.rom` | `4b1dd6eb` |

## Notes

- MAME driver: `zx.cpp`.
- MAME clone of `zx81` (ZX-81) — the system macro's parent field in the driver source. The ROM table above lists every member this machine's own zip needs.
